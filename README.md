# School Site

Сайт для школы с уведомлением об ограничении ответственности перед входом.

## Структура
- `index.html` — стартовая страница с юридическим дисклеймером и кнопкой «Принять».
- `next.html` — основная страница сайта (в разработке).
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.

## Как работает
1. Пользователь открывает сайт.
2. Читает уведомление об ограничении ответственности.
3. Нажимает «Принять» — происходит переход на `next.html`.
4. Факт принятия сохраняется в `localStorage` (можно использовать для повторных визитов).

## Деплой
Хостится бесплатно через **GitHub Pages**.
